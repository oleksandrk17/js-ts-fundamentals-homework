# Космічна гра (JavaScript: Objects, Events, Exceptions)

Навчальна гра на чистому JavaScript, DOM та подіях. Гравець керує фіолетовим кораблем унизу поля і знищує зелені кораблі чужинців, які опускаються зверху.

## Як запустити

Відкрити `index.html` у браузері (Chrome). Збірка та сервер не потрібні.

## Керування

- **← / →** — рух корабля вліво/вправо
- **Пробіл** — постріл (з'являється промінь). Постріл працює лише після натискання Start і не працює після завершення гри
- **Select Speed** — вибір швидкості (1–5)
- **Start** — початок гри (також перезапуск після перемоги чи поразки)

## Що реалізовано відповідно до вимог завдання

| Вимога | Реалізація |
|---|---|
| Поле 8×11, розміри відносні, розмір клітинки — константа | `FIELD_WIDTH`, `FIELD_HEIGHT`, `CELL_SIZE` |
| Знищити всі кораблі чужинців, які опускаються зверху вниз | Сітка 8×3 чужинців, спуск рядів за таймером (`setInterval`) |
| Керування кораблем з клавіатури: вліво, вправо, постріл | Подія `keydown`, межі поля перевіряються |
| Швидкість обирається на початку гри через форму | `select` + кнопка Start, значення зчитується й перетворюється на число |
| Швидкість — дискретна величина, що множиться на часову константу | `BASE_INTERVAL / speed` (більша швидкість дає менший інтервал) |
| Очки за кожен знищений корабель — константа | `POINTS_PER_SHIP`, відображення в `Score` |
| Збільшення швидкості після кожних 10000 очок | `SPEED_UP_SCORE`, перезапуск таймера з новим інтервалом |
| Промінь від корабля гравця до корабля чужинця | `showBeam`: промінь до верху цілі (або до верху поля), зникає через 150 мс |
| Обробка виняткових ситуацій | `try/catch` в обробнику Start, `throw new Error("Invalid speed")` |
| Події | `keydown`, `click`, `setInterval`, `setTimeout` |

## Відхилення від завдання та обмеження

- **Перегенерація кораблів замінена перемогою.** За завданням після знищення всіх чужинців гра продовжується з новим масивом. Тут при знищенні всіх з'являється повідомлення `YOU WON!`, гра зупиняється, а нова сітка створюється після натискання Start. Через це поріг прискорення в 10000 очок на практиці недосяжний (максимум за одну сітку — 2400 очок), але логіка реалізована і перевірялась зниженням порога.
- **Корабель — не клас/об'єкт із методами.** Кораблі це DOM-елементи (`div`), а їхня поведінка винесена у функції (`createAlien`, `moveAliensDown`, `fire`, `showBeam`). Окремого об'єкта з атрибутами та методами, як вимагає завдання, немає. Планується окрема версія з ООП.
- **Швидкість рахується діленням:** інтервал = `BASE_INTERVAL / speed`. Часова константа підібрана експериментально (1000 мс).
- **Поразка:** гра зупиняється, коли ряд чужинців доходить до клітинки над кораблем гравця (не перекриває його).
- **Верхньої межі швидкості немає:** після кожних 10000 очок вона зростає без обмеження.

## Додатково (понад вимоги)

- Перемога та поразка через `alert`
- Перезапуск гри кнопкою Start (`resetGame`)
- Захист від повторного запуску таймера при кількох натисканнях Start (`clearInterval` перед новим `setInterval`)
- Прапорець `isGameRunning`: стріляти можна лише під час гри
- `boxSizing: border-box` для рамок чужинців
- Центрування гри на сторінці

## Структура

- `index.html` — розмітка (поле, панель Score/Speed, форма)
- `style.css` — стилі
- `game.js` — уся логіка гри
